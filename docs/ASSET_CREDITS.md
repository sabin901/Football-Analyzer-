## Pappalardo / Wyscout research archive

Luca Pappalardo, Paolo Cintia, Alessio Rossi, Emanuele Massucco, Paolo Ferragina, Dino Pedreschi and Fosca Giannotti (2019). A public data set of spatio-temporal match events in soccer. Scientific Data 6, 236. [Paper DOI](https://doi.org/10.1038/s41597-019-0247-7). Data provided by Wyscout. [Dataset collection](https://doi.org/10.6084/m9.figshare.c.4415000).

The event, match, team and player articles are published under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Downloaded files are checksum pinned; source article IDs, file IDs, license records and SHA-256 values accompany the build.

Changes: names decoded, positions grouped, coordinates rescaled, counts and progressive-action metrics derived, regulation minutes estimated, spatial grids aggregated and shots selected. The source provides no xG. Displaying this research archive does not imply affiliation or endorsement by Wyscout, the authors, clubs or competitions. This permission applies to this specific research release, not to the commercial Wyscout platform or arbitrary match video.

## Interface

League selector marks are original country monograms, not official league logos. Team marks are text initials. Third-party player portraits and provider logos are not requested by this release. The Footlyzer wordmark and layout are project assets.

Interface icons derive from Lucide under its ISC license. The license is included as LUCIDE_LICENSE.txt. System fonts avoid remote font requests.

## User imports and code

Users must have permission to use their own imported event files and videos. They remain in their browser and are not redistributed by this application. No permission to use a third-party video is granted by a data license.

Public source code availability is separate from dataset rights. This release does not grant a new blanket license over all repository code or third-party material. Individual notices continue to apply. Restricted legacy research artifacts are excluded from the public build; historical Git revisions are not purged by this release.

## Team identifiers

Footlyzer generates its own shield identifiers from each team name. These are navigation aids, not official club crests, and their colours are not a claim about club colours. No club endorsement is implied. The shared renderer supports reviewed local assets under `assets/clubs/`; an asset must have documented permission before being added. Football-Data.org's subscription does not itself grant permission to use team graphics.
