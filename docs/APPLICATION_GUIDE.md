## The practical benefit of this project

| Target role | Evidence to demonstrate | Additional evidence to prepare |
|---|---|---|
| Football data analyst | Python ingestion, SQL, missing value handling, spatial analysis and readable reports | A Power BI or Excel report, football interpretation and stakeholder feedback |
| Recruitment analyst | Position specific comparison, sample awareness and player maps | A defined role brief, video checks, contextual adjustments and feasible recommendations |
| Performance analyst | Match summaries, shot locations, activity patterns and briefing exports | Video coding, tactical vocabulary, coaching communication and deadline experience |
| Sports software engineer | FastAPI, a responsive interface, automated checks, deployment and reproducible data | Explain architecture, debugging, failure recovery, security and your individual contribution |
| Junior football data scientist | Temporal cutoffs, baselines, proper scoring rules and calibration | Statistical reasoning, prospective evaluation and validated improvements |

## Prepare an application package

- Link the live site and repository. Identify your contribution and any AI assistance honestly.
- Write one page answering one question: for example, how a player's recorded action distribution differs from their team's, and what should be checked on video next.
- Include a reproducible query, the sample and source, one clear chart, an interpretation and a limitation.
- Prepare a three minute walkthrough and be ready to explain the calculations and fix a small bug without assistance.
- Tailor the CV to one role. Avoid describing the software as a Premier League system or claiming guaranteed prediction accuracy.

Suggested CV wording, only if you can explain and defend the work: Built and deployed a football analytics application combining current league summaries with historical event data, spatial visualizations, a SQL warehouse and forecast evaluation, supported by automated data validation and documented limitations.
